# AI 先提供只读家庭问答，并要求回答依据

状态：已批准。

知家首期 AI 采用只读的「家庭问答」能力，覆盖家庭事实与成员明确选中的知识来源，不调用任何写入命令；统一入口必须区分回答使用的依据。家庭事实回答显示数据来源与查询时间，知识来源回答显示附件及可定位内容位置；无法获得可靠依据时必须明确拒答或说明无法确认。这样保留现有库存与附件的权威边界，也避免把自然语言生成结果误当成可追溯的家庭事实。

## 后果

- 家庭问答可以提供相关业务页面的跳转入口，但不能代替库存、物品、提醒或附件的既有写流程。
- `全局搜索` 继续表示确定性的中文子串匹配，不能作为家庭问答的别名。
- 知识来源是附件的显式用途选择，不改变附件的挂载点、生命周期或文件类型。
- 家庭附件作为全家庭知识来源；物品附件适用于该物品及其批次；批次附件只适用于该批次。所有活跃成员沿用现有附件权限，可以选择、查询和取消知识来源。
- 首期只处理可提取文字的 PDF、Markdown、TXT、DOCX、XLSX 和 PPTX；扫描版 PDF、图片与 HEIC 等待后续 OCR 能力。
- 知识准备采用异步流程，用户可见「处理中 / 可用 / 失败 / 已停用」状态；附件上传成功不代表知识已可检索。
- 首期不在服务端长期保存对话历史；浏览器当前会话内容与持久化的知识数据严格分开。
- 首期以两个最小纵向切片交付家庭事实问答和知识来源问答，统一入口支持根据问题推荐范围；物品或位置名称有歧义时先展示候选让用户确认。
- 一条回答可以同时使用家庭事实和知识来源，但必须分别标注两类依据，不得静默混合或让一方覆盖另一方。
- 回答呈现为自然语言摘要、结构化结果和回答依据三层；库存与位置优先结构化展示，知识来源优先展示步骤与附件定位。
- 未来若增加写入草稿、确认执行或自动操作，需要另行定义命令权限、确认和审计边界。
