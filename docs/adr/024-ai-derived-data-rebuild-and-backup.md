# AI 派生知识数据可重建，备份以原始附件和选择为准

状态：已批准。

备份包含原始附件、知识来源选择和必要配置；抽取文本、分块与向量索引视为可重建的派生知识数据，不要求备份绑定某个模型或索引格式。恢复时先恢复原始附件与选择，再按当前可用的处理能力重新准备知识来源。这样备份保持与附件事实一致，也避免模型或索引升级后被旧向量格式锁定。

## 后果

- 恢复后的家庭问答可能在知识重新准备完成前暂时不可用，界面必须显示知识准备状态。
- 备份清单需要区分原始附件、知识来源选择和派生知识数据，不能把后者冒充为附件事实。
- 处理模型、分块规则或索引结构变化时，可以通过重建派生知识数据完成调整，不必修改原始附件。当前项目处于开发阶段，计划不为历史版本兼容、旧数据迁移或升级回滚增加额外约束。
