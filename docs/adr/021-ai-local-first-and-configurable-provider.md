# AI 采用本地优先且可配置的模型提供方

状态：已批准。

知家保持私有部署的默认边界：AI 默认不把家庭事实或知识来源内容发送到外部服务；家庭管理员可以明确配置外部模型提供方，作为可选能力。未配置可用模型时，家庭问答不可用但库存、附件和其他核心流程必须继续完整运行。该选择在本地隐私、家庭服务器资源和模型可替换性之间取平衡，避免把产品锁死在单一云服务或单一本地模型上。

## 后果

- 模型提供方、凭据、出网开关和发送字段必须成为管理员可见的系统设置，并且默认关闭外部数据传输。
- 当前有效的模型提供方由管理员统一配置，普通成员不能按单次提问切换提供方。
- 外部提供方不是核心业务依赖；AI 服务故障或未配置不能阻塞家庭数据写入和附件生命周期操作。
- 调用外部提供方时只发送当前问题、必要的检索片段和最小元数据；不发送完整附件、完整家庭数据集或历史对话。
- 外部提供方应关闭内容留存或使用其可提供的最短留存策略，不得把家庭内容用于模型训练。
- AI 请求受部署和成员级资源限制约束，包括请求频率、单次上下文大小、处理并发和超时；限制或失败原因对管理员可见。
- 后续需要单独定义外部调用的数据最小化、日志脱敏、错误重试和提供方兼容契约。
