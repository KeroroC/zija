# 知识来源跟随附件生命周期并显式表达回答新鲜度

状态：已批准。

知识来源是附件的派生用途，不是独立文件类型。附件进入回收站后立即停止参与家庭问答，恢复后重新准备，改挂后按新挂载点改变检索范围，改名只更新回答依据，永久删除时清除抽取文本与索引。家庭问答必须区分家庭事实和知识来源：家庭事实负责当前状态，知识来源负责其内容范围；回答显示可定位依据和数据时间，来源不可用或过期时明确说明无法确认，不以模型常识或联网搜索填补空缺。

## 后果

- 知识索引必须具备与附件生命周期同步的停用、重新准备和清理路径，不能仅依赖文件卷对象是否仍存在。
- 当前库存、提醒和流水等家庭事实需要通过受控查询来源提供新鲜度信息；不能让模型依据单次检索结果自行推算跨页汇总或隐藏延迟。
- 当结构化家庭事实与附件内容不一致时，回答必须分别呈现，不得让生成模型静默选择一方。
- 没有可验证知识来源的问题只能明确拒答或说明无法确认，首期不调用通用知识或互联网搜索。
